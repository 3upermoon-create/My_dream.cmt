# Bet Analyst AI V1

## Features
- Automatic today's fixtures through API-Football
- Fixture detail/prediction/odds retrieval
- Poisson probability calculator
- Implied probability and EV
- BET CANDIDATE / WAIT / NO BET labels
- Bankroll calculator
- Basic betting journal storage

## Run locally
Set API_FOOTBALL_KEY, then:
pip install -r requirements.txt
python app.py

## Render
Use render.yaml and add API_FOOTBALL_KEY in Environment Variables.

This is an analysis tool, not a guaranteed-profit system. API coverage varies by league/endpoint.
